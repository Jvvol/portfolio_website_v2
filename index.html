About Me

My name is Jacob Wolfe, and I'm an aspiring software developer. I'm currently a senior at West Virginia University, pursuing a major in Computer Science and a minor in Music Technology. I'm actively seeking internship opportunities where I can apply my skills, learn from experienced developers, and contribute to meaningful projects. Some of the classes I've taken include File and Data Structures, Advanced Software Engineering, Computer System Concepts, Analysis of Algorithms, Calculus 3, Discrete Mathematics, Operating Systems, Compiler Construction, Intro to Pro Tools, and Practicum Recording Technology.

My primary language is Java, but I've also worked extensively with C++, C, JavaScript, TypeScript, and PHP. In my database design class, I helped build RoomTG, a roommate matching system, and in my advanced software engineering course I worked on Byte-Sized, a mobile allergen-filtering app that helps users find local restaurants best suited to their allergies and dietary preferences. Both projects were built with PostgreSQL and TypeScript. I've also built this portfolio site and a handful of other websites for client projects, and I'm currently working on an audio plugin called "Aether Delay," built with the JUCE framework and C++ in Visual Studio to create a clean, customizable delay effect.
